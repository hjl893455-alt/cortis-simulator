# CORTIS · 恋爱模拟器

虚构平行世界互动小说（PWA，可安装到手机离线玩）。建立你的角色、选择故事主角，在练习室、外景地之间推进剧情：回应、试探、保持距离——每个选择都会影响好感度与故事数值。

> 完全虚构的平行世界故事。角色均为成年设定，剧情不对应现实人物或事件。

## 📱 手机系统（v3 新增）

游戏现在是一台虚拟手机：锁屏 → 主屏幕（状态栏实时时钟）→ 4 个 App：

- **微信**：和每位角色私聊 + 练习生群聊。发消息对方会"正在输入…"然后回复——回复看关键词、好感度、游戏内地点/时间，每个人说话风格不同。剧情短信会自动变成微信消息，群聊每几回合自己聊起来
- **电话**：通讯录 / 拨号盘 / 通话记录。能给角色打电话（选项式对话，加好感）；第 3 回合经纪人来电催行程，第 6 回合主角来电问"刚才那场戏怎么样"
- **故事**：原有剧情玩法不变
- **相册**：每推进两回合解锁一张"照片"，共 6 张

多人房间里，客人的微信 / 通话记录 / 相册会实时同步房主的（只读）。

## 👥 多人房间（v2 新增）

不用搭服务器，打开即玩：

1. 房主在首页切换到「👥 多人房间」，填好角色设定后点「创建房间，开始故事」，拿到 4 位房间码
2. 把房间码或「复制邀请链接」发给朋友
3. 朋友点「加入朋友的房间」（或直接打开邀请链接），输入昵称 + 房间码
4. 之后每一回合：大家一起投票决定剧情走向（25 秒倒计时，全员投完或房主手动提前结算），票数实时同步，还能在房间里聊天

技术：PeerJS P2P 直连，无中心服务器；房主是故事的唯一数据源。

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署

纯静态文件，推到 GitHub 后在仓库 Settings → Pages 里选 `main` 分支即部署，多人模式开箱即用。
